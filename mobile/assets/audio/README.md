# Audio Files for Meditation Sessions

This directory should contain the meditation audio files. Please add the following MP3 files:

- `river.mp3` - River sounds meditation
- `trees.mp3` - Forest/trees meditation
- `beach.mp3` - Beach waves meditation
- `yosemite.mp3` - Yosemite nature sounds meditation
- `waterfall.mp3` - Waterfall sounds meditation

Each audio file should be a tranquil audio recording (approximately 10 minutes each, though duration can vary).

## How to Add Audio Files

1. Place your MP3 files in this directory (`assets/audio/`)
2. The app will automatically detect and load them when users select a meditation session
3. Audio will play with playback controls (play/pause) and progress tracking

## File Requirements

- Format: MP3 (`.mp3` extension)
- Duration: Recommended 5-15 minutes
- Quality: 128-192 kbps recommended for mobile
- Content: Tranquil, nature-based soundscapes

## Error Handling

If audio files are missing, the app will gracefully handle the error and display a loading message to the user without crashing.
